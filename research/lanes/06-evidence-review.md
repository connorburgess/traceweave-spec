No removal cost or success rate for that complete pass was measured here.

### SEW: useful mechanics, two decisive audit flags

Author pin: `3c873186a56033e73347391b7aedebce1f7f71d0`, commit date 2026-10-01. The [license](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/LICENSE) is MIT; the paper's separate publication license must not be substituted for the software license.

Static audit of [embed.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/sew/embed.py), function `embed`: discovers guarded sites, applies keyed target edits, reparses, checks unchanged bytes outside edit footprints, iterates to a bounded fixed point, and rolls back on listed failures. These checks detect specific rewrite failures; they do not establish observational equivalence. An `ok` result can include zero edits and does not by itself establish sufficient detection evidence.

**Flag A — advertised flipping percentage is not changed-site percentage.** In [attacks/flip.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/attacks/flip.py), `atk_flip(q < 1)` selects a site with probability `q`, then writes a uniformly random variant. Expected changed sites are therefore approximately `q/2` of eligible discovered sites, before overlapping edits or other failures. At `q >= 1` it instead inverts every site. The [attack registry](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/attacks/__init__.py) maps `flip50` to `q=0.5` and `flip75` to `q=0.75`. Consequently the supplied 50/75 settings cannot be read as 50/75% actual inversion without reconciling paper and code. The discontinuity at full budget also matters. This is source evidence, not a reproduced explanation of the published curves.

**Flag B — guards do not justify a universal safety claim.** In [c_family_rules.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/sew/rules/c_family_rules.py), `E2Commutative.guard` excludes literal string operands for `+`, then accepts an atomic other operand; it does not require that an identifier have a numeric type. Candidate unexecuted Java counterexample: `String s = "a"; String t = s + 1;` versus `String t = 1 + s;` gives order-sensitive concatenation. Whether the complete embedder selects this site/key is untested; the inspected local guard alone does not exclude it. `E1Compare.guard` relies on `is_pure`, which classifies array/field access as pure and performs no whole-program effect or overloaded-operator proof. Treat these as static audit concerns, not measured failures of this release.

**Cheapest plausible removal, inference:** normalize all safely recognized style pairs to one public canonical variant, then rediscover and test. This needs no target-key recovery. If target votes are insufficiently neutralized, remove eligible evidence or change structural context through valid refactoring. Full inversion is a stronger target, not the cheapest attack requirement. None of these removal proposals was executed.

## Capacity, calibration and semantic transfer gates

The following are review requirements/inferences, not additional published measurements:

- Count requested inputs, accepted inputs, changed inputs, already-matching inputs, failed validations and rollbacks separately. Count raw sites, feasible states, deduplicated evidence grades and net recovered identity bits separately. Framing, redundancy, synchronization and catalogue discrimination consume capacity. A 128-bit key does not imply 128 payload bits.
- SEW's [detect.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/sew/detect.py), `detect`, majority-votes equal structural identifiers, uses rule probabilities, and takes twice the smaller of all-rule and syntax-rule tails. [config.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/sew/config.py) sets `MIN_EVIDENCE=5`, `N_TESTS=2`, `ALPHA=0.01`. Five grades is a refusal threshold, not a demonstrated minimum recoverable fragment or useful capacity guarantee.
- [stats.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/sew/stats.py), `poibin_sf`, computes an independent-Bernoulli tail. Aggregation reduces one source of dependence; it does not prove all remaining grades independent or make estimated style probabilities exact for Go/Rust or other populations.
- [scripts/evaluate.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/scripts/evaluate.py), `tpr_at_fpr`, sweeps thresholds on the supplied positive and negative scores. This estimates a benchmark ROC operating point, not a frozen threshold's held-out full-search false-alert guarantee. Distinguish this output from `tpr_at_alpha` and from the CLI verdict. [evaluate_attacks.py](https://github.com/suhanmen/SEW/blob/3c873186a56033e73347391b7aedebce1f7f71d0/scripts/evaluate_attacks.py) records attack exceptions and detection scores; its inspected attack loop does not run semantic-equivalence checks. Invalid attacks and failed transformations need separate denominators.
- Calibrate complete negative queries after searching every allowed window, anchor, key and candidate identity and after result merging. Include unmarked code, wrong keys/identities, independently authored same-task code, common boilerplate, partial copies and transplants. Repeated code variants and multiple keys on the same program are clustered observations. Correcting two internal SEW tests does not correct an unbounded external search.

**Proposed Go/Rust subset, unimplemented:** if any transfer is later considered, begin with one explicitly typed primitive-integer comparison-orientation pair on immutable local value operands. Require resolved bindings, supported complete compilation units, fixed toolchain/configuration and no source observers. This is a proposed restriction, not established eligibility. Refuse pointers, indexing, calls, overloaded operations, floating-point rewrites and unsupported syntax. The obvious canonicalization reverses the same pair; new syntax alone provides no robustness claim.

For Go, require package-wide scope/type analysis before renaming; exclude public API/reflection-sensitive names and any change to evaluation, panic or concurrent-observation order. For Rust, exclude macros, `cfg` branches not analyzed, build scripts/source inclusion, unsafe/FFI, user-defined traits and changes affecting borrowing, temporaries or `Drop`. These are proposed refusal boundaries, not a reviewed port. Literal-spelling extensions remain particularly exposed to canonicalization. No blanket semantics argument transfers from C++/Java/Python.
