It retains UTF-8 SHA-256 values for each original `text`, `sentence` and `correction` field, plus a hash of each original row serialized as compact, key-sorted, non-ASCII-preserving JSON. Omitted text is not encoded elsewhere. The ledger is a historical baseline mapping with subsequent dispositions; it is not a regenerated original inventory, a new source census or proof of zero remaining unmapped sentences. The original claim-map SHA-256 remains `01532072204aff379bb565e7115d0b9c97c0273920256c54def96066588743a8`.

The original map, if separately available, can be checked against its whole-file hash and the ledger's per-row hashes. At each accepted correction tip, compare the named baseline, inspect the listed occurrences/changed properties and verify the disposition scope. Access to S/W/I or the original retained artifacts is a dependency for their full text-level recheck; this package deliberately does not claim public reconstruction of omitted text.
