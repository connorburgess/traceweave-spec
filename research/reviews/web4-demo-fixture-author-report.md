Earlier default catalogue contents were not established; a pre-existing default could have been replaced. No restoration was attempted without knowing prior contents. This unintended write outside the package is explicitly disclosed, not represented as an isolated successful run. The subsequent comparison omission occurred after temporary private-directory isolation was added. Go extraction/validation flag differences were then corrected using its existing README. Every successful recorded run uses explicit stdout outputs and temporary private storage; no default-private contents were read as input.
